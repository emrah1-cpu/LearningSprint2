3. Inspect the actual bits

Every group represents four bits. The bit patterns are identical whether they are interpreted as signed or unsigned; only their numerical meaning changes.

4. Understand the process

    Important C-language distinction: Unsigned arithmetic wraps modulo 2n in C. Signed overflow in C is undefined behavior; this demo intentionally shows fixed-width, two's-complement wraparound as a hardware concept, not a promise about how every C program behaves.
